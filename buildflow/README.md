# BuildFlow 🏗️

מערכת לניהול פרויקטי בנייה והנדסה — מהשטח ועד המשרד.
**Local-first PWA**: עובדת במלואה ללא שרת וללא רשת; הנתונים נשמרים במכשיר (IndexedDB) ומוכנים לסנכרון ענן עתידי.

### 🌐 גרסה חיה: **[buildflow-indol.vercel.app](https://buildflow-indol.vercel.app)**

> האפיון המלא: [SPEC.md](./SPEC.md) · הוראות פיתוח: [CLAUDE.md](./CLAUDE.md)

## הרצה

```bash
npm install
npm run dev        # פיתוח — http://localhost:5173
npm run build      # בדיקת טיפוסים + בנייה ל-dist/
npm run preview    # הרצת גרסת ה-build
```

בכניסה הראשונה נטען אוטומטית פרויקט דמו — **"מגדלי הפארק, בניין A"** — עם מבנה מלא (6 קומות × 4 דירות), תוכנית קומה, 24 ליקויים, משימות ויומני עבודה.

## משתמשי הדמו

| משתמש | תפקיד | מה רואים אצלו |
|-------|-------|----------------|
| אלון | מנהל מערכת | הכול |
| רונית לביא | מנהלת פרויקט | ניהול מלא של הפרויקט |
| יוסי פרץ | מפקח | יצירת ליקויים, בדיקות ואישורים |
| סמי כהן | קבלן חשמל | **רק** הפריטים של חשמל כהן |
| אבי לוי | קבלן אינסטלציה | **רק** הפריטים של אינסטלציה לוי |

החלפת משתמש: תפריט האווטאר → "החלף משתמש". שווה להיכנס כקבלן כדי לראות את סינון ההרשאות בפעולה.

## מה עובד (שלבים 1–5 + חלקי 6–7)

- ✅ פרויקטים: רשימה, אשף יצירה עם תבניות מבנה (מגורים / משרדים / תשתית)
- ✅ עץ מיקומים גנרי: אתר → בניין → קומה → דירה → חלל, כולל יצירה מרובה ו-badges
- ✅ תוכניות: העלאה (**PDF**/PNG/JPG/SVG — כולל בחירת עמוד מ-PDF רב-עמודי), צופה עם pan/zoom/pinch
- ✅ **סיכות על תוכנית**: נעיצת ליקוי בנקודה מדויקת, צבע לפי סטטוס, מיקוד מפריט
- ✅ **עיגון קואורדינטות (ITM)**: כיול בשתי נקודות, קריאת נ.צ. חיה, נ.צ. לכל סיכה, "עבור לנ.צ." ונעיצת ליקוי לפי קואורדינטה
- ✅ **"המיקום שלי"**: GPS חי על גבי תוכנית מכוילת — נקודה כחולה עם עיגול דיוק, המרת WGS84→רשת ישראל מובנית
- ✅ ליקויים: מחזור חיים מלא (פתוח→בטיפול→לבדיקה→סגור/נדחה), תמונות עם דחיסה, שיחה, היסטוריה
- ✅ משימות: לוח Kanban, חסימות, התקדמות
- ✅ תמונות: גלריה לפי יום, לפני/אחרי, קישור לפריט
- ✅ יומן עבודה: טיוטה → הגשה → נעילה
- ✅ **סימון על גבי תמונות**: חץ / מלבן / עיגול / חופשי / טקסט ב-3 צבעים — וקטורי, המקור לא נפגע
- ✅ הרשאות: 4 תפקידים; קבלן רואה רק את הפריטים שלו
- ✅ דשבורד: KPI לחיצים, התפלגויות, מגמה, חריגות
- ✅ **דוחות מעוצבים**: דוח ליקויים מקובץ (קומה/קבלן), דוח ליקוי בודד עם סימונים, דוח יומן עבודה עם חתימות — דרך הדפסת הדפדפן ("שמור כ-PDF"), עברית מושלמת גם offline
- ✅ התראות פנימיות, ייצוא CSV, מצב כהה, RTL מלא

## מה הלאה (ראה SPEC §16)

רשימות תיוג ו-QA · Backend (Supabase) וסנכרון בין מכשירים · Push והתראות דוא"ל ·
לוח זמנים ו-Look-Ahead · דוח התקדמות להנהלה.

## סטאק

React 18 + TypeScript + Vite · Tailwind CSS v4 · Dexie (IndexedDB) · Zustand · React Router · vite-plugin-pwa

## פריסה

**Vercel** — [buildflow-indol.vercel.app](https://buildflow-indol.vercel.app). הפרויקט ב-Vercel מריץ סקריפט דק שמושך את הריפו הציבורי מ-GitHub ובונה את `buildflow/`, כך שכל פריסה מחדש לוקחת את הקוד העדכני מהענף. לחיבור אוטומטי (deploy על כל push) יש לקשר את הריפו ב-Vercel Dashboard → Project → Settings → Git, עם **Root Directory = `buildflow`**.

**קובץ יחיד** — `npx vite build --config vite.artifact.config.ts` יוצר `dist-artifact/index.html` שמכיל את כל האפליקציה (כולל מנוע ה-PDF) בקובץ אחד, עם ניתוב hash. שימושי לשליחה במייל או לפתיחה offline בדאבל-קליק.
