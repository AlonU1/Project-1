# מערכת בקרה תקציבית לפרויקטי תשתית

אפליקציית ווב לניהול אומדן, תזרים, לוח זמנים ובקרת ערך מזוכה (EVM) בפרויקטי בנייה ותשתית.
נבנתה מתוך גיליון "אומדן ובקרה תקציבית" והורחבה למערכת בקרה מלאה.

---

## יכולות

| אזור | תיאור |
|---|---|
| **① תכנית בסיס** | האומדן והלו"ז לפני תחילת ביצוע. ניתן לנעילה כדי לשמר תכנית קפואה להשוואה. |
| **② תכנית מתעדכנת** | עדכון שוטף: תאריכים, משכים, אחוזי ביצוע. גאנט עם גרירה, ופס בסיס אפור מתחת לכל פעילות. |
| **③ השוואה + EVM** | PV / EV / AC / SPI / CPI / EAC / ETC / VAC, עקומות S, מגמת SPI-CPI, וניתוח מילולי אוטומטי. |
| **④ דשבורד** | שלוש תצוגות: מנהלים (מדי SPI/CPI, אבני דרך, התקדמות פרקים) · לוח זמנים (סטיות מול בסיס, גאנט השוואתי) · כספים (תזרים, פערי אישור-תשלום, עכבון). |
| **⑤ חשבונות** | חשבונות חלקיים מצטברים: חוזה, חריגים/נוספים, מאושר מול שולם בפועל, ועכבון. |
| **⑥ ניתוח AI** | תובנות אוטומטיות מחושבות מהנתונים + ניתוח מלא ע"י Claude (דורש מפתח API אישי — נשמר בדפדפן בלבד, לא בענן). ניתן לכלול את הניתוח בדוח. |
| **⑦ דוח** | דוח חודשי מעוצב: לוגו, תמצית KPI, עקומות S, ניתוח וטבלאות — מוכן להדפסה / PDF ב-A4 אנכי. |

**נוסף:** ריבוי פרויקטים · נתיב קריטי · אבני דרך · תלויות סיום-התחלה עם דחיפה אוטומטית · ייבוא/ייצוא Excel · שמירה אוטומטית בענן · פריסת תזרים יחסית-לימים · חיווי ענן/מקומי.

## הרצה מקומית

```bash
npm install
cp .env.example .env     # מלא את פרטי Supabase (אופציונלי)
npm run dev
```

ללא Supabase האפליקציה עובדת מלא ושומרת ב-localStorage.
עם Supabase — הנתונים משותפים בין מכשירים ומשתמשים.

## בנייה לפרודקשן

```bash
npm run build     # פלט לתיקיית dist/
npm run preview   # תצוגה מקומית של הבנייה
```

## פריסה לרשת

ראה `DEPLOY.md` למדריך מלא (Supabase + Vercel/Netlify).
`supabase.sql` יוצר את טבלת הנתונים.


## מודל החישוב

- **תזרים:** עלות הפעילות (לאחר הנחת קבלן) נפרסת שווה על חודשי הפעילות.
- **PV:** מתכנית הבסיס, בפריסה ליניארית עד תאריך הסטטוס.
- **EV:** אחוז ביצוע × תקציב הבסיס של הפעילות.
- **AC:** חשבון מאושר מצטבר (חוזה + חריגים).
- **תזרים בפועל:** "שולם מצטבר" — נפרד מ-AC, כדי למדוד פער אישור-תשלום.
