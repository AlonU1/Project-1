# סנכרון לענן — Google Sheets + Drive

האפליקציה שומרת הכול מקומית בטלפון (גם בלי קליטה), ובנוסף יכולה **לדחוף כל רשומה אוטומטית לגיליון Google Sheets** כשיש אינטרנט. התמונות עולות ל-Google Drive וקישור אליהן מופיע בגיליון. רשומות שנוצרו בלי קליטה ממתינות בתור ונשלחות אוטומטית כשחוזרת הרשת.

> זו דחיפה **חד-כיוונית** (אפליקציה → גיליון). האפליקציה נשארת המקור הרשמי; הגיליון הוא עותק חי / גיבוי שאפשר לצפות בו ולשתף.

## התקנה — פעם אחת (~5 דקות)

1. היכנס ל-[Google Sheets](https://sheets.new) וצור **גיליון חדש**.
2. בתפריט: **Extensions → Apps Script**.
3. מחק את הקוד הקיים בעורך, והדבק את כל התוכן של הקובץ **`AppsScript.gs`** (נמצא כאן בתיקייה). שמור (אייקון הדיסקט).
4. למעלה מימין לחץ **Deploy → New deployment**.
5. ליד "Select type" לחץ על גלגל השיניים ובחר **Web app**.
6. הגדר:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
7. לחץ **Deploy**, ואשר את ההרשאות (Drive + Sheets — לחץ Allow).
8. העתק את ה-**Web app URL** (מסתיים ב-`/exec`).
9. באפליקציה: במסך הבית לחץ **☁️**, הדבק את הכתובת בשדה, ולחץ **שמור כתובת**.

זהו. מעכשיו:
- כל רשומה חדשה/מעודכנת נדחפת לגיליון אוטומטית כשיש קליטה.
- כפתור **☁️** מציג כמה רשומות ממתינות לסנכרון.
- אפשר ללחוץ **🔄 סנכרן עכשיו** לדחיפה ידנית.

## מה מופיע בגיליון
עמודות: מזהה, פרויקט, כתובת, סוג, אזור, מיקום, תיאור, קטגוריה, חומרה, קבלן, טלפון, סטטוס, תאריך יעד, GPS, קישור מפה, נוצר, סונכרן, וקישורי תמונות (ב-Drive).

## הערות
- עדכון רשומה קיימת **דורס** את אותה שורה ואת תמונותיה (לפי המזהה) — אין כפילויות.
- מחיקת רשומה באפליקציה מוחקת גם את השורה בגיליון (כשיש קליטה).
- אם תפרסם **גרסה חדשה** של הסקריפט (Deploy → Manage deployments → Edit), הכתובת נשארת אותו דבר.
- הסנכרון דורש HTTPS (כמו שאר היכולות) — כלומר דרך GitHub Pages, לא מקובץ מקומי.
