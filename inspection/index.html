☁️ סנכרון לענן (Google Sheets)

1. צור גיליון חדש ב-Google Sheets.
2. תפריט Extensions ← Apps Script.
3. הדבק את הקוד מהקובץ inspection/sync/AppsScript.gs שבריפו.
4. Deploy ← New deployment ← Web app. הגדר: Execute as = Me, Who has access = Anyone.
5. אשר הרשאות, העתק את כתובת ה-Web app (מסתיימת ב-/exec) והדבק למעלה.
