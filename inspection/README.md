# אפליקציית פיקוח אתר בנייה

אפליקציית web עברית (RTL) מותאמת מובייל ו-**PWA שעובד בלי אינטרנט**, לניהול פרויקטים, תיעוד ליקויים ומשימות באתר בנייה, מעקב תיקונים, וייצוא דוח לאקסל — כולל תמונות לפני/אחרי ומיקום GPS.

## תכונות
- **פרויקטים**: מסך בית עם רשימת פרויקטים. נכנסים לפרויקט ומנהלים את הרשומות שלו. מגדירים פעם אחת — לא צריך להזין שוב.
- **אזורים / מבנים / חללים**: רשימת אזורים לכל פרויקט; בוחרים מהם בכל רשומה (אזור חדש שמקלידים נשמר אוטומטית).
- **סוגי רשומות**: לא רק ליקויים — גם **משימת ביצוע**, **אישור/בדיקה** ו-**הערה**. סינון לפי סוג.
- **מעקב סטטוס**: פתוח → בטיפול → לתיקון חוזר → סגור, עם דשבורד וסינון לכל פרויקט.
- **גלריית תמונות**: כמה תמונות לכל רשומה, כל אחת מתויגת «לפני» או «אחרי» (תיעוד התיקון).
- **סימון על התמונה**: עורך מובנה לציור חצים, מסגרות וקו חופשי בצבעים שונים — להדגיש את הליקוי בדיוק על התמונה.
- **הערה קולית + הכתבה**: הקלטת קול לכל רשומה, וכפתור הכתבה קולית (Speech-to-Text בעברית) למילוי התיאור וההערות בלי להקליד.
- **GPS**: נתפס מ-GPS המכשיר בזמן התיעוד, עם קישור Google Maps. כולל הזנה ידנית של קואורדינטות כגיבוי.
- **דוח PDF לחתימה**: הפקת דוח מעוצב (כותרת, טבלה, תמונות, מקומות חתימה למפקח ולקבלן) דרך הדפסה → «שמור כ-PDF». כולל חתימה דיגיטלית של המפקח (pad) ואפשרות לסנן לפי קבלן/סטטוס.
- **שליחה ישירה בוואטסאפ**: שיתוף תמונת הדוח ישירות לוואטסאפ (Web Share API) — הקובץ מצורף. אם המכשיר לא תומך: שמירת התמונה + פתיחת צ׳אט עם הקבלן וטקסט מסכם.
- **ייצוא לאקסל**: קובץ `.xlsx` אמיתי (RTL) לכל פרויקט — עם **התמונות מוטמעות בתאים**, GPS, קישור מפה, כותרת, סינון אוטומטי והקפאת כותרת.
- **גיבוי / שחזור**: ייצוא וייבוא של כל הנתונים לקובץ JSON (להעברה בין מכשירים / גיבוי).
- **עבודה לא-מקוונת**: Service Worker מאחסן את האפליקציה ואת הספריות (אקסל + רינדור) — עובד מלא גם בלי קליטה.

## חשוב — HTTPS (GPS / מיקרופון / הכתבה / שיתוף)
דפדפנים מאפשרים מיקום, מיקרופון, הכתבה קולית ושיתוף קבצים **רק בהקשר מאובטח** (HTTPS או localhost). אם פותחים את הקובץ מהדיסק (`file://`) הם לא יעבדו — תופיע התראה בראש המסך. הפתרון: להגיש את האתר ב-HTTPS.

### הפעלה ב-GitHub Pages (מומלץ)
1. ב-GitHub: **Settings → Pages**.
2. Source: הברנץ׳ הרלוונטי, תיקייה `/ (root)`.
3. האפליקציה תהיה זמינה בכתובת `https://<user>.github.io/<repo>/inspection/`.
4. כעת GPS, התקנה כאפליקציה ועבודה לא-מקוונת — עובדים.

## אחסון
הנתונים נשמרים **מקומית בדפדפן** (`localStorage`, ~5MB). מומלץ לגבות לקובץ מדי פעם (כפתור «💾 גיבוי»). ניקוי נתוני הדפדפן ימחק את המידע — לכן הגיבוי חשוב.

## תלויות
- [ExcelJS](https://github.com/exceljs/exceljs) ו-[html2canvas](https://github.com/niklasvh/html2canvas) — מאוחסנים מקומית ב-`vendor/` (לא תלויים באינטרנט).
- ה-PDF מופק דרך מנגנון ההדפסה של הדפדפן (ללא ספרייה) — תמיכה מושלמת בעברית.

## רעיונות להמשך
- **תזכורות** על רשומות שעבר תאריך היעד שלהן.
- היררכיית אזורים (מבנה ← קומה ← חלל) ותגיות חופשיות.
- חתימת הקבלן דיגיטלית בתוך האפליקציה (לא רק שורת חתימה בדוח).
- ייצוא PDF רב-עמודי עם עמוד נפרד לכל ליקוי.
- סנכרון ענן אופציונלי (כרגע הכל מקומי במכשיר).
