# אפליקציית פיקוח ליקויים

אפליקציית web עברית (RTL), מותאמת מובייל, לניהול פרויקטים, תיעוד ליקויים באתר בנייה, מעקב אחר תיקונם, וייצוא דוח לאקסל — כולל תמונות ומיקום GPS.

## תכונות
- **פרויקטים**: מסך בית עם רשימת פרויקטים (שם, כתובת, מזמין). נכנסים לפרויקט ומשם מנהלים את הליקויים שלו.
- **אזורים / מבנים / חללים**: בכל פרויקט מגדירים פעם אחת רשימת אזורים, ובוחרים מהם בכל ליקוי (אפשר גם להוסיף אזור חדש תוך כדי — הוא נשמר אוטומטית לפרויקט).
- **תיעוד ליקוי**: תיאור, אזור, מיקום מדויק, קטגוריה, חומרה, קבלן אחראי, תאריך יעד, צילום, הערות.
- **מעקב סטטוס**: פתוח → בטיפול → לתיקון חוזר → סגור.
- **דשבורד לכל פרויקט**: ספירת פתוחים / באיחור / נסגרו + סינון לפי סטטוס וחיפוש.
- **תמונה + GPS**: צילום מהטלפון (נדחס ונשמר מקומית). בזמן התיעוד נתפס מיקום ה-GPS של המכשיר ונשמר עם קישור ל-Google Maps.
- **ייצוא לאקסל**: קובץ `.xlsx` אמיתי (RTL) לכל פרויקט — עם **התמונה מוטמעת בתא**, קואורדינטות GPS וקישור מפה, כותרת, סינון אוטומטי והקפאת שורות.

## לגבי ה-GPS
כשהדפדפן דוחס את התמונה, נתוני ה-EXIF המקוריים (כולל GPS) נמחקים. לכן המיקום נתפס מ-**GPS המכשיר בזמן התיעוד** (Geolocation API) — מדויק יותר, כי זה המיקום שלך בפועל באתר. בפעם הראשונה הדפדפן יבקש הרשאת מיקום. אפשר גם לתפוס מיקום ידנית בכפתור «📍 תפוס מיקום GPS».

## איך מריצים
פתח את `index.html` בדפדפן. במובייל: "הוסף למסך הבית" כדי שיתנהג כאפליקציה. לתפיסת GPS נדרש שהאתר יוגש ב-HTTPS (או localhost).

## אחסון
כל הנתונים (כולל תמונות) נשמרים **מקומית בדפדפן** (`localStorage`) — בלי שרת, בלי הרשמה. מומלץ לייצא לאקסל מדי פעם לגיבוי. מגבלת אחסון ~5MB, כך שכמות התמונות מוגבלת — ייצוא וניקוי תקופתי מומלץ.

## תלויות
- [ExcelJS](https://github.com/exceljs/exceljs) נטען מ-CDN לצורך ייצוא אקסל עם תמונות. שאר האפליקציה עצמאית.

## רעיונות להמשך
- מצב לא-מקוון מלא (Service Worker / PWA מותקנת).
- הפקת דוח PDF לחתימה ושליחה לקבלן בוואטסאפ/מייל.
- תמונות "לפני/אחרי" לכל ליקוי.
- גיבוי/שחזור הנתונים לקובץ (ייצוא/ייבוא JSON).
- היררכיית אזורים (מבנה ← קומה ← חלל).
