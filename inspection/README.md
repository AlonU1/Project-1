# אפליקציית פיקוח ליקויים (אב-טיפוס)

אפליקציית web עברית (RTL), מותאמת מובייל, לתיעוד ליקויים באתר בנייה, מעקב אחר תיקונם, וייצוא דוח לאקסל.

## תכונות (MVP)
- **תיעוד ליקוי**: תיאור, אתר/פרויקט, מיקום, קטגוריה, חומרה, קבלן אחראי, תאריך יעד, צילום, הערות.
- **מעקב סטטוס**: פתוח → בטיפול → לתיקון חוזר → סגור.
- **דשבורד**: ספירת ליקויים פתוחים, באיחור, נסגרו + סינון לפי סטטוס וחיפוש חופשי.
- **צילום מהטלפון**: התמונה נדחסת ונשמרת מקומית.
- **ייצוא לאקסל**: קובץ `.xlsx` אמיתי (RTL) בלחיצה אחת.

## איך מריצים
פתח את `index.html` בדפדפן. במובייל אפשר "הוסף למסך הבית" כדי שיתנהג כאפליקציה.

## אחסון
כל הנתונים נשמרים **מקומית בדפדפן** (`localStorage`) — בלי שרת ובלי הרשמה. מומלץ לייצא לאקסל מדי פעם לגיבוי. ניקוי נתוני הדפדפן ימחק את המידע.

## תלויות
- [SheetJS](https://sheetjs.com) (xlsx) נטען מ-CDN לצורך ייצוא אקסל. שאר האפליקציה עצמאית.

## רעיונות להמשך
- תמיכה מלאה במצב לא-מקוון (Service Worker) ו-PWA מותקנת.
- הפקת דוח PDF לחתימה ושליחה לקבלן.
- ניהול מספר אתרים/פרויקטים נפרד.
- צירוף התמונות עצמן לקובץ הייצוא / תיקיית ZIP.
- תמונות "לפני/אחרי" לכל ליקוי.
